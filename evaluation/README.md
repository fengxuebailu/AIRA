# Prompt inventories

| File | Contents |
| --- | --- |
| `single_subject_local_prompts.json` | Single-subject DreamBench and showcase prompts |
| `two_subject_reconstructed.json` | Two-subject test prompts and proposed validation prompts |
| `three_subject_local_config.json` | Three-subject prompts and layouts |
| `four_subject_local_config.json` | Four-subject prompts and layouts |

Each file records its scope and source. The two-subject file includes reconstructed candidates; it is not a record of the original held-out validation prompts. Generated benchmark images and metric results are not included.
